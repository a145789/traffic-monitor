# RFC 审计：找候选 → 带证据的中文笔记

只产出笔记：**不改 `src/`、不提交、不开 PR**。实施与 PR 归 `rfc-ship`。

## 只读 code

文档策略以 `AGENTS.md` 为准：它通常已由 harness 注入上下文，**在上下文里就别再 read 一遍**；若不在（少数 harness 不注入），**读一次、只取第 1–9 条受保护接缝**。默认姿态是**只读 code**：除 `docs/rfc/README.md`（笔记格式的规范）与你要判断撞车的待办笔记外，不读 `docs/` 下任何内容——含 `docs/archive/`，历史与已实施笔记都在那里，可能过时且体量约等于整个 `src/`。不要为「更全面了解项目」而通读任何目录。

## 第 0 步：查重

```
grep -rn "^Status: *proposed" docs/rfc/
```

只认 `docs/rfc/<会话目录>/` 下的笔记文件；`docs/rfc/README.md` 里的是示例。**0 条就直接开工**，不要为了「了解上下文」去翻 archive。有命中时用符号级 grep 判断撞车：符号在 `src/` 里存在才可能重叠，此时才读那篇的「提案 / 明确不在本次范围」；符号已不存在 ⇒ 早已实施，跳过（可在交付说明里指出状态字过期）。

## 环境事实

- **`rg` 不在 PATH**：用 grep 工具（搜索不需要先 read 文件）或 `Select-String`。给子代理下指令时必须交代。
- 纯 Rust + Win32，`src/` 共 17 个源文件；生产语料还包括 `build.rs`、`scripts/*.ts`、`.github/`、`installer.iss`、`Cargo.toml`。
- 测试全部内联在 `src/` 的 `#[cfg(test)]`，无 `tests/`、无 `examples/`。
- **没有自动死代码工具**（无 `cargo-machete` / `cargo-udeps`），依赖面的证据只能手工取：`cargo tree -i <crate>`、`grep -rn "<crate>::" src`。
- 用户可见字符串一律中文；笔记正文用中文。

## 核心动作：分类消费者

- **生产语料**：`src/*`、`build.rs`、`scripts/*.ts`、CI 与 loader 配置、`installer.iss`。
- **非生产语料**：`#[cfg(test)]` 测试、README、`docs/`、注释。
- **模糊语料**：可能是产品冒烟路径的脚本——**读用法再归类**。

先精确 grep 符号（`名称`、`name(`、`.name(`、事件名、配置键、线上字符串），**再读调用点**。工具不能替代理解。

## 什么算强候选

- 没有生产消费者的公开方法 / 事件 / 配置项 / 辅助函数 / 常量。
- 测试或文档是唯一消费者，且它们钉死的行为不承重。
- **同一事实有两份表示**：标志镜像集合、调用方平行实现纯函数已承担的职责。
- 接缝上每个实现都必须支持、却没有消费者使用的方法。
- 只为测试或演示存在的包或依赖，带来发布或依赖开销。
- **推测性产品通用性**：为没有产品归属者的场景预留的开关 / 分支 / 状态位。
- 不可达分支、永不触发的兜底、没有生产者的错误路径。
- **手写代码重复实现了标准库或已依赖 crate 的能力**，且替换能删掉实现**加**其专用测试（要说明残余语义，残余语义计入反对票）。
- **弱测试**：注释声称守护某性质，但把被测代码换成注释所指的错误实现后断言仍通过——必须同时证明删除不减保护（该性质另有更强的用例覆盖）。

判据只看当前 code 证据；**不要把记忆里的历史案例当检索关键词**（历史教训常已修完，照着找会得到一堆假候选）。

## 什么不算 / 直接降级

- 拿不出调用点证据的「看着复杂」；错别字；单行等价改写。
- 有真实生产调用方 → 降级为产品决策，写进「被否决」而不是提案。
- 删除 `AGENTS.md` 保护的接缝本身，或用户未授权的架构级删除。
- 旧笔记里提过、但当前 code 已不存在的问题（已实施）。

想法正确但太小 → 加一条行内 `TODO(tag)`，不要立笔记。

## 写笔记

位置、命名、格式、写作要求的**唯一真值是 `docs/rfc/README.md`**（约 3.5 KB）——**动手前先读它**，照它写；本 skill 不复述这些细节，以免两处漂移。

## 子代理（候选面广时才用）

按域并行：`update` / `renderer`+`tray` / `window`+`suspend` / `collector`+`main` / 依赖+构建+测试面。提示词只需交代：只读 code、不读 `docs/`、`rg` 不可用、三分法、输出格式（标题 / 符号与 `file:line` / 生产消费者或「无」附检索命令 / 非生产消费者 / 提案动作 / 最强反方 / 净删行数 / 重叠），并要求列出被否决的候选。子代理通常已自动收到 `AGENTS.md`（先确认；拿不到就把第 1–9 条摘进提示词），因此**不要复述接缝清单**。宁可 3 条证据硬的，不要 10 条薄的。

## 交付时说明

新增几篇、各覆盖什么；刻意排除了什么（受保护接缝、被否决的候选）；若有自己纠错后放弃的，讲明。需引入新的隐式约束时才考虑更新 `AGENTS.md`，按它自己的「更新指南」办。
